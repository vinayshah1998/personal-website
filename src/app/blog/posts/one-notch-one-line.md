This week was about scrolling in fullscreen mode, which turns out to be very personal.

One wheel notch used to scroll 3 rows. I changed it to 1, which felt precise but slow. Now it's a Scroll speed setting of 1, 2, or 3, defaulting to 2. While a response streamed, some notches were dropped entirely, because of a merge step that kept the larger of two values instead of adding them. That's fixed.

Other small things from the week:

- Retry notices read "attempt 2/3" and name the model.
- `/clear` keeps your current model and effort.
- Homebrew installs leave updates to brew.
- Markdown tables handle escaped pipes.
- 120 Hz rendering is now an experimental opt-in.

None of these is a headline. Together they're the difference between a tool you tolerate and one you like.
